# راهنمای توسعه

## ساختار و مسئولیت‌ها

```
ai/                     موتورهای پایتون (مرجع منطق + قابل تست)
tests/                  50 تست pytest - هر تغییر اینجا اعتبارسنجی می‌شود
training/               پایپ‌لاین داده و مدل (دانلود → QC → آماده‌سازی → آموزش → ارزیابی → خروجی)
android/app/            اپ کاتلین (mirror کامل موتورها + سرویس‌های Native + UI)
documentation/          همه مستندات
```

## قانون طلایی: دو پیاده‌سازی هم‌گام

منطق تاکتیکی دو بار نوشته شده (Python برای تست و آموزش، Kotlin برای اجرا روی گوشی). اگر الگوریتمی را تغییر دادید، **هر دو سمت را هم‌زمان تغییر دهید** و در پیام کامیت بنویسید. قرارداد JSON خروجی باید یکسان بماند (بخش 5 معماری).

## تست‌ها و توسعه

```bash
python -m pytest tests/ -q          # سریع (<1s) — قبل از هر کامیت
python -m pytest tests/ -q -k elixir   # فقط یک موتور
```

پوشش تست‌ها: هندسه زمین (نقاط مرجع، ناحیه استقرار، پل/رودخانه)، tracker (پایداری ID، occlusion، rescue کم‌اطمینان)، اکسیر (regen/double/cap/پلی حریف/missed play)، چرخه کارت (دیسکاوری، تکامل، قهرمان، پیش‌بینی)، placement (اعتبار نقاط، پول، طلسم)، تاکتیک (سناریوهای Hog/هوایی/swarm/SAVE/ATTACK) و توابع نوری (letterbox/NMS).

## افزودن کارت جدید

1. نام کلاس باید با دیتاست هم‌خوان باشد (لیست `ai/data/classes_full.json`).
2. آمار تقریبی را به `ai/data/cards.json` اضافه کنید (elixir/kind/target/speed/hp/dps/count/roles؛ `flying: true` اگر یونیت هوایی است).
3. همان فایل در `android/app/src/main/assets/cards.json` هم هست (کپی کنید).
4. اگر قهرمان است، `"champion": true` بگذارید؛ موتور چرخه خودش مدیریت می‌کند.
5. برای مدل: کلاس جدید فقط وقتی وارد خروجی مدل می‌شود که در دیتاست آموزش داشته باشد.

## پایپ‌لاین داده

- دانلود فقط زیرمجموعه معنادار را می‌گیرد (crops + 2 شارد synthetic + CSVها) — نه 12.3GB کامل.
- `prepare.py` بعد از استخراج موفق، پارکه‌ها را حذف می‌کند؛ اگر چیزی استخراج نشود، حذف نمی‌کند (گارد).
- Split همیشه **گروهی** است (ویدیو/مسابقه) — هیچ مسابقه‌ای بین train/val/test نمی‌افتد.
- برای دیتاست بیشتر: `track_grades/` شامل کادرهای واقعی 99 ویدیوست؛ frames باید از ویدیوی خودتان بازسازی شود (`rebuild_video_frames.py` در ریپو دیتاست).
